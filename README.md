1. شبکه
اول از همه یه اتصال شبکه بر روی پروتکل tcp ایجاد میشه، با ایپی و پورت مشخص، که اینجا 127.0.0.1:8000 هست
بعد یه درخواست http ارسال میشه، که متد های خاص خودشو داره، و درنهایت از سمت سرور یه پاسخ دریافت میشه، یا همون response

2. جلوی ایپی و پورت سرور میاد (دامنه)، و نشون میده به کاربر که از کدوم مسیر سایت داره استفاده میکنه

3. همون بخشی از جنگو هست که مسیر ها رو به view متناسبشون لینک میکنه، یه جور table درواقع
اگه هم مسیر پیدا نشه ارور http 404 میده

4. همون تابع یا کلاسی هست که وظیفه داره درخواست ها رو دریافت کنه، پردازش کنه و درنهایت پاسخ متناسب رو برگردونه
بعنوان مثال توی کد ما که این باشه

from django.http import HttpResponse

def hello_world(request):
    return HttpResponse("Hello World John Doe")

پارامتر request یک شی هست که حاوی همه جزئیات درخواست میشه
که در اینجا این تابع یک متن ساده برمیگردونه
